# 記事の書き方

記事は`src/content/posts/`にMarkdown／MDXで追加する。`src/content/posts/`からの相対パスがURLになり、`abbey-road.md`は`/posts/abbey-road`で公開する。

## フロントマター

フロントマターには次の項目を書く。

```yaml
---
title: 「アビイ・ロード」を2026年に聴く
created: 2026-10-25
updated: 2026-10-26
icon: cd
thumbnail: ./img/abbey-road.jpg
tags:
  - ロック
  - The Beatles
author: mush1to
---
```

| 項目 | 内容 |
| --- | --- |
| `title` | 記事名。100文字以内で書く。省略した場合は本文の最初のH1見出し（`#`）を使い、H1見出しがない場合はファイル名を使う |
| `created` | 作成日を`YYYY-MM-DD`形式で書く。トップページの「作成日時」に表示し、新しい順に並べる。省略した記事は一覧の最後に並ぶ |
| `updated` | 更新日を`YYYY-MM-DD`形式で書く。記事ページの「更新日時」に表示する。省略した場合は`created`と同じ日時になる |
| `icon` | 記事一覧と検索結果に表示するアイコン。`document`（文書）・`music`（音符）・`cd`（CD）から選ぶ。省略した場合は`document` |
| `isPublished` | 真偽値。`false`にすると記事を公開しない。記事ページ・記事一覧・RSSフィード・検索のすべてから除外する。省略した場合は`true` |
| `thumbnail` | 見出し画像。`img/`内のファイルを記事ファイルからの相対パスで書く。形式はjpg・jpeg・png・webpで、推奨サイズは1200×630。記事の先頭に表示し、OGP画像とXの大きな画像付きカードにも使う。ファイルがない場合や`src/content`の外を指す場合はビルドが失敗する |
| `tags` | タグを文字列の配列で書く。先頭の`#`は取り除き、重複はまとめる。記事の末尾にタグページへのリンクとして表示する |
| `author` | 著者のユーザーID。[`src/content/users.yaml`](../src/content/users.yaml)に登録したIDを書く。省略した場合は`src/config/site.ts`の`site.author`を使う。登録していないIDを書くとビルドが失敗する。登録方法は[ユーザー](users.md)を参照する |

## 記事の説明

記事の説明はフロントマターには書かず、本文から自動で作る。本文の先頭にある段落をそのまま説明に使い、検索エンジン向けの説明とRSSフィードに出力する。

- 段落より前の見出しは使わない。見出しで始まる記事でも、最初の段落を説明にする
- 段落のない記事では見出しを、見出しもない記事では空文字を使う
- 強調・リンク・インラインコード・画像の記法は取り除き、文字だけを残す
- 段落の折り返しは日本語では詰め、英数字の間だけ半角スペースにする
- MDXの`import`やJSXは説明に含めない
- 140文字を超える場合は先頭139文字を残し、末尾に「…」を付けて合計140文字にする

## 画像

記事で使う画像は`src/content/posts/img/`に置く。見出し画像も本文中の画像も同じフォルダに入れる。

見出し画像は`thumbnail`に記事ファイルからの相対パスで書く。記事の見出し画像は装飾画像として扱うため、代替テキストは書かない。

```yaml
thumbnail: ./img/abbey-road.jpg
```

本文中の画像も同じフォルダを指す。

```md
![「Abbey Road」のジャケット](./img/abbey-road.jpg)
```

形式はjpg・jpeg・png・webpのいずれかにする。ファイルがない場合や`src/content`の外を指す場合はビルドが失敗する。ビルド時にファイルの内容からハッシュ付きのURLを作って配信するため、同じファイルを差し替えるとURLも変わる。

## About

Aboutは記事置き場の外にある`src/content/about.mdx`から生成する固定ページで、URLは`/about`である。記事一覧とRSSフィードには含めない。記事のファイル名に`about`を使った場合は、通常の記事として`/posts/about`で公開する。ルート直下の`index`はトップページになるため記事には使わない。サブディレクトリの`index`はそのディレクトリのURLで公開する。
